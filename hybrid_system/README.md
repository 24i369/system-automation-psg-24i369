Hybrid Industrial Machine Monitoring System

About
This project combines the Day 1 logical rule engine and Day 2 Machine Learning model to monitor industrial machines and identify possible problems.

Features
- Generates sensor readings for temperature, pressure, vibration, current, and RPM.
- Uses logical rules to check machine conditions.
- Uses a Random Forest model to predict machine status.
- Combines both results to decide the final status and action.
- Saves the results in a log file.

Technologies Used
Python, Machine Learning, Random Forest, Scikit-learn.
